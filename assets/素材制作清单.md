# StudyNest 手绘素材制作清单

> 用途：替换页面里内置的矢量房间与小猫，让展示更有手绘温度。
> 交付方式：**按文件名放进对应目录即可**，代码不用改（缺失的素材会自动回退到内置矢量版）。
> 交付时间：11/4–11/6 期间画完，11/7 我统一接入 + 彩排。

---

## 一、画前统一规范（两个人必须先对齐）

| 项 | 要求 |
|---|---|
| 画布 | 透明背景 PNG（不要白底、不要描边外框） |
| 导出倍率 | 按下面表格的**画布尺寸**导出（已经是屏幕显示尺寸的 2 倍，肉眼看清晰即可） |
| 分辨率 | 72 dpi 足够（网页用），单张 ≤ 200KB，宠物 ≤ 400KB |
| 主体留白 | 四周留 **8% 安全边距**，主体居中，不要顶格 |
| 描边 | 统一 4–6px 暖褐色描边（参考 `#a87f67`），线宽全组保持一致 |
| 阴影 | **不要画投影**（页面 CSS 会加柔和阴影），只画物件本身 |
| 光源 | 统一左上方（窗户光），高光放在左侧/上方 |
| 禁止 | 不要画文字、不要画整个房间背景（只画单件物件） |

## 二、分工

- **A（画宠物）**：4 张，360×360 —— 工作量小但要求表情准确
- **B（画房间）**：6 件，见下表 —— 件数多但都是静物

> 想调节奏的话：A 画完 4 张宠物后可帮忙画「装饰彩蛋」（第 4 节）。

---

## 三、A — 宠物小猫（4 张 · 360×360 · `assets/pet/`）

同一只猫、同一姿势基准，只改表情和细微体态；**4 张必须能无缝切换**（身体轮廓、位置、比例完全一致，只有表情/耳朵/尾巴变化）。

| 文件名 | 状态 | 画面要点 |
|---|---|---|
| `idle.png` | 待机（默认） | 坐姿正面，眼睛圆睁有神，尾巴自然垂在身侧，嘴巴微闭。页面会做轻微上下浮动（呼吸），所以**底部要留 8% 空白**，否则浮动时会贴边 |
| `studying.png` | 学习中 | 同一坐姿，**眼睛半闭成弧线**（专注/微眯），耳朵略前倾，最好爪子前伸搭在书/笔上；不要画台灯（灯由页面单独绘制） |
| `resting.png` | 休息打盹 | 姿势改为趴卧或蜷缩，眼睛闭成两道弯线，尾巴卷到身前，可加 1–2 个 `z` 气泡（浅灰蓝） |
| `celebrate.png` | 完成庆祝 | 站姿或半立，眼睛弯成笑眼（^ ^），嘴巴张开笑，前爪抬起，周围可画 3–5 个金色小星星/彩纸（不要太密，页面还会有闪光动画） |

**注意**：`celebrate` 那张会在页面上做跳跃动画（上下 20px、轻微旋转），左右各留 10% 余量更安全。

## 四、B — 房间物件（6 件 · `assets/room/`）

页面里房间是按 680×479 渲染的，下表「画布」已是 2 倍，按这个尺寸画就行。**透视统一为正视（front view）**，不要俯视。

| 文件名 | 画布尺寸 | 页面显示尺寸 | 画什么 |
|---|---|---|---|
| `window.png` | **360 × 400** | ≈177×192，位置左上 | 拱形顶（上圆下方）的窗户：外侧木框 + 中间横向窗棂 + 玻璃内的远山/云/小太阳。**窗框要和玻璃分开画**，玻璃区半透明淡蓝绿渐变 |
| `shelf.png` | **400 × 90** | ≈184×13，位置右上 | 一块木质搁板 + 板下两个三角形小托架。**板上可以放 3–4 本书和 1 个小盆栽**（书脊用暖色系，别用高饱和） |
| `desk.png` | **660 × 280** | ≈326×128，位置右下 | 书桌正面：桌面（浅木）+ 左右两条桌腿 + 桌面下一条横撑。桌面可放 1 支笔筒/1 本摊开的书，但**不要画电脑**（展示时和任务卡片打架） |
| `lamp.png` | **130 × 170** | ≈65×85，位置桌面右上 | 台灯：圆形/锥形灯罩 + 细灯杆 + 小底座。**灯罩内部用暖黄 `#ffe5a0`**，学习状态页面会给它加发光效果，所以灯罩别画太暗 |
| `plant.png` | **160 × 240** | ≈80×120，位置左下 | 盆栽绿植：陶土盆 + 3–5 片叶子（橡皮树/龟背竹都行）。页面会做轻微摇摆（以盆底为轴），**盆底离画布底边留 8% 空白** |
| `rug.png` | **880 × 240** | ≈442×115，位置底部中间 | 椭圆形地毯（俯视略扁的透视），中心一块浅色织纹 + 外圈双层描边。**画成横向椭圆**，不要正方形 |

### 可选（画了就加分，不画也完全能演示）

| 文件名 | 画布 | 内容 |
|---|---|---|
| `sun.png` | 80 × 80 | 圆形太阳光斑（如果觉得现在 CSS 的圆太生硬） |
| `books.png` | 200 × 120 | 窗户下方的一摞书（替代现在的 emoji 📚🌷） |
| `pet-bed.png` | 300 × 140 | 小猫的软垫（放地毯上，`resting` 状态更自然） |

## 六、自查清单（交给我前逐条过一遍）

- [ ] 背景是透明的（在深色底上检查一遍，别有白边/灰边）
- [ ] 尺寸和表格完全一致（像素值对得上）
- [ ] 4 张宠物是同一只猫、同一比例、同一描边宽度
- [ ] 没有画投影（页面自己加）
- [ ] 每个文件小于体积上限
- [ ] 文件名、所在目录完全正确
- [ ] 在浅色 `#faf5ec` 底上看一遍，边缘没有锯齿/白毛边

## 七、验收与风险

1. 我收到素材后会写一个加载器：图片存在就用图片，不存在自动回退内置矢量，页面绝不报错。
2. 建议 11/6 前发我第一版（哪怕只画完宠物 4 张），我接入后截图给你看效果，再决定要不要调。
3. **素材本身不会影响功能演示**——即使一张都没画完，11/9 也照常展示，只是画面朴素一点。
